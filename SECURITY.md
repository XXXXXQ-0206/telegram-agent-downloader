# Security Policy

## Supported Versions

Only the current `main` branch is supported.

## Reporting A Vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability
reporting or security advisory features when available. If those features are not
available, open an issue with a minimal reproduction and avoid posting secrets,
account identifiers, private message links, downloaded media names, cookies,
local paths, or browser profile data.

## Data Handling

This repository must not contain runtime data. Do not commit downloaded media,
browser profiles, cookies, local storage, account sessions, logs, Saved Messages
manifests, absolute local paths, or private Telegram links.
